# theme-x

把 Halo 博客变成 X（原 Twitter）。左栏导航、中间 600px 时间线、右栏搜索与趋势，
三套背景配六种强调色，无限滚动、键盘快捷键、图片灯箱一并还原。

- Halo 版本要求：`>= 2.20.0`（在 Halo 2.26.1 上实测通过）
- 图标依赖 [iconify](https://iconify.design)（CDN 可在「外观 → 图标脚本地址」里换）

> `theme.yaml` 的 `spec.author.name` 不能留空——Halo 会校验这个字段，空字符串直接安装失败。

## 安装与升级

**最省事的办法：远程下载。** 后台「外观 → 主题 → 安装主题 → 远程下载」，下载地址填：

```
https://codeload.github.com/bocmiao/theme-x/zip/refs/heads/main
```

这个地址永远指向最新版。没装过就是安装；已经装过的话 Halo 会弹「主题已存在，是否升级？」，
点确认就升级到最新，**主题设置会保留**。以后每次升级都是粘同一个地址、点两下。

> 用 `codeload.github.com` 而不是 `github.com/…/archive/…`：后者只是一个跳转，
> 国内服务器经常连不上 `github.com` 本身（实测 Halo 会报 `Failed to unzip theme`，
> 日志里是 `Connection timed out: github.com:443`），而 `codeload` 上才是真正的文件。
> 如果你的服务器连 `codeload` 也连不上，就只能手动上传 zip 了。

**手动上传**：把仓库打成 zip（`theme.yaml` 要在压缩包根目录，或者整个包只套一层目录也行，
Halo 会自己识别），后台「安装主题 → 本地上传」。

### 后台一键更新（theme-x 助手）

装一个小插件，以后就不用再粘地址了：GitHub 上有新版本时，后台会自己提示，点一下就更新。
这个插件还带两页：「内容 → 友链 RSS」一键给所有友链自动发现 RSS 地址（见
[首页的第二个标签页](#首页的第二个标签页正在关注)）；「内容 → 友链体检」定时检查友链还能不能打开（见
[友链体检](#友链体检)）。

**装一次**（先按上面的办法把主题升级到 1.13.5 或更新，插件就在主题里带着）：
后台「插件 → 安装 → 远程下载」，地址填 `https://你的域名/themes/theme-x/assets/plugins/theme-x-updater.jar`，
装好后点「启用」。
插件本身有新版本时（CHANGELOG 里会写），在「插件」列表里它那一行点「⋯ → 升级」，远程下载填同一个地址。

**之后每次更新**：

- 进后台会弹一条「theme-x 有新版本 x.y.z」的提示（每个版本每次打开浏览器提示一次）；
- 「主题 → 主题管理」里 theme-x 那一行会多一个「**更新到 x.y.z**」按钮，点开能看到这一版改了什么
  （取自仓库里的 `CHANGELOG.md`），确认后十几秒完成，**主题设置保留**，页面自动刷新；
- 想放在仪表盘上也行：仪表盘「设置 → 添加部件 → 小部件中心 → 其他」里有「theme-x 更新」部件。
  Halo 的仪表盘按屏幕宽度分别存布局（电脑、平板、手机各一份），手机上也想看到就在手机布局里再加一次。

查版本和更新走的都是上面那个 `codeload` 地址（从压缩包里的 `theme.yaml` 读版本号），
所以只要「远程下载」能用，这个插件就能用。检查结果在服务器上缓存 10 分钟，部件右上角可以手动重新检查。

### 上传自动转 WebP

另一个随主题带的小插件：后台传图片时，先在浏览器里把 PNG / JPEG 转成 WebP 再传，
体积通常只剩三分之一到十分之一（实测 4.77 MB 的图变 530 KB）。服务器上什么都不用装。
附件库、编辑器里粘贴的图片、主题设置里选图上传都走这条路。

装法一样：后台「插件 → 安装 → 远程下载」，地址填
`https://你的域名/themes/theme-x/assets/plugins/webp-upload.jar`，装好点「启用」。
质量、最长边上限、多小的图不转，都在插件自己的设置里调。

**装了但没转？** 打开后台，按 F12 看控制台：插件在工作的话会有一行「[webp-upload] 已就绪」；
上传一张 PNG 之后，在控制台输入 `window.__webpUpload.seen` 能看到每次上传的判定结果
（转了多少、或者为什么没转）。插件更新方式：「插件」列表里它那一行的「⋯ → 升级」，远程下载填同一个地址。

> Halo 本身不做格式转换（缩略图用 Thumbnailator，按原格式输出），所以这一步只能在上传前做。
> 已经传上去的老图片不受影响，想换成 WebP 只能重新传一次。

两个插件的源码都在仓库的 `plugins/` 目录，不会打进主题包；编译好的 jar 在 `templates/assets/plugins/` 下随主题分发。

把整个目录打包成 zip 上传，或者用官方 CLI：

```bash
npm install && npm run build
```

## 页面对应关系

| 导航项 | 走的路由 | 模板 |
| --- | --- | --- |
| 首页 | `/` | `index.html` |
| 探索 | 归档路由（默认 `/archives`） | `archives.html` |
| 分类 | 分类路由（默认 `/categories`） | `categories.html` / `category.html` |
| 标签 | 标签路由（默认 `/tags`） | `tags.html` / `tag.html` |
| 书签 | `/bookmarks` | `page_bookmarks.html`（没建页面时由 `error/404.html` 兜底） |
| 个人资料 | `/about` | `page_about.html` |
| 媒体 | 自己定（比如 `/media`） | `page_media.html` |
| 瞬间 / 图库 / 友链 | 对应插件的路由 | `moments.html` / `photos.html` / `links.html` |

「书签」和「个人资料」对应的是**自定义页面模板**：

1. **个人资料**：Halo 初始化时已经自带一个别名为 `about` 的「关于」页面，直接编辑它，
   把「自定义模板」选成「关于」即可。不设的话 `/about` 就是一张普通页面。
2. **书签**：**不建也能用。** 主题注册不了路由，所以 `/bookmarks` 没有对应页面时会落到 404 模板，
   而 404 模板里备了一份书签容器——脚本发现路径是 `/bookmarks` 就直接画书签列表。
   唯一的差别是这个地址的 HTTP 状态码是 404；书签本来就只存在访客本机，对搜索引擎没有意义。
   介意的话新建一个页面，别名填 `bookmarks`、自定义模板选「书签」，就是正经的 200 了。

> 别再新建第二个别名叫 `about` 的页面——两个页面抢同一个地址，解析到哪个是不确定的
> （实测会时而落到没套模板的那个上）。

| 名称 | 用在哪 | 文件 |
| --- | --- | --- |
| 长文 | 文章 | `post_longform.html`：正文按文章排版，附目录与阅读进度 |
| 关于 | 页面 | `page_about.html`：X 个人主页样式，含横幅与资料行 |

## 无刷新切页

点站内链接不再整页重载：只把中间那一栏换掉，左栏和右栏**原地不动**。
没有白屏，右栏的滚动位置、搜索框里已经打的字、展开着的菜单全都保持原样。
浏览器支持 View Transitions 的话还会带一层很短的淡入淡出（180ms）；不支持就是直接换，只少一层过渡。

在「功能 → 无刷新切页」里可以关掉，关掉就是传统的整页跳转。

**下面这些链接不接管**，一律交给浏览器：外站、`target="_blank"`、带 `download`、
按住 Ctrl/Cmd/Shift/Alt 点的、中键点的、`/console` 与 `/apis` 这类后台与接口、
以及 `rss.xml`、`sitemap.xml`、图片附件这种带后缀的静态文件。
想让某个链接强制整页跳转，给它加 `data-no-swap`。

**出任何问题都退回整页跳转**：目标不是 HTML、状态码不是 200（比如 404）、
跨域重定向、或者解析失败，都会直接 `location.href` 过去，不会把人卡在半路。

> **二次开发注意。** 中栏是整块换掉的，所以写在 `main` 里的 `<script>` 不会执行。
> 每页都要跑的逻辑写进「高级 → 自定义 JS」，并且自己判断当前路径；
> 需要对新进来的节点做加工的话，用 `window.XTheme.enhance(节点)`。
> 另外，主题内部给「按页初始化」准备了卸载表（`onPage` / `intervalPage`），
> 自定义脚本往 `window` / `document` 上加的监听和定时器不在其中，换页时不会自动清理。

## 左栏底部的两块

- **「更多」** 点开是一个小菜单：显示、键盘快捷键、RSS 订阅、后台管理
  （和手机抽屉里「设置与支持」那一组是同一批入口）。按 <kbd>Esc</kbd>、点菜单外面、或者再点一次按钮都能收起，上下方向键可以在菜单项之间移动。
- **底部的头像那一行** 点了去「个人资料」页，地址跟着「左栏导航 →「个人资料」指向的地址」走。
- **「收起侧边栏」= 切成博客的样子。** 宽屏（≥ 1300px）下点一次：左栏收成纯图标条，
  中栏把省下来的 187px 全吃掉（600 → 787px，**三栏整体位置和两边留白都不动**），
  文章列表切成博客样式，顶上的发帖框收起来。再点一次回到 X 的样子。
  选择记在访客自己浏览器里；窄屏本来就是图标条，这个按钮不显示。
  收起之后还想单独调列表样式，标签栏右边那个按钮和「显示」面板里照旧管用。

> 这两块以前绑的是同一个动作（都打开「显示设置」），点哪个结果都一样，属于白占一行。
> 现在按 X 的分工拆开了：X 的「More」是导航溢出菜单，账号行是账号菜单。

## 个人主页那排标签

「帖子 / 媒体 / 书签」这排标签放的是**同一批内容的不同切面**：全部文章、带图的、访客收藏的。
出现在 `/archives`、`/media`、`/bookmarks`、`/about` 和作者页上，当前所在的那一格高亮。

- 「媒体」要在「左栏导航 →「媒体」标签指向的地址」填了才出现（见下一节）；
- 「书签」跟着「功能 → 书签」的开关走；
- 两项都关掉就只剩「帖子」一格，这时整排不画。

> 1.20.0 之前这里还有「列表」「话题」两格，点开分别是分类页和标签页——和左栏的「分类」「标签」
> 是同一个页面，一处内容两个入口、还是两套名字。现在分类和标签只留在左栏（站点级导航），
> 这排只管「我的内容怎么看」。


## 首页的第二个标签页（「正在关注」）

X 的「正在关注」是你关注的人发的新内容。博客里最接近的东西就是**友链**，所以这一格在
「主题设置 → 首页 → 第二个标签页取什么内容」里可以选：

| 选项 | 内容 |
| --- | --- |
| 最多访问 | 最近这些文章里访问量最高的（默认） |
| 指定分类 | 某个分类下的文章 |
| **友链** | 朋友们的最新文章；取不到就列友链本身 |

选「友链」时：

1. 先要「链接」插件抓回来的**友链 RSS 动态**——朋友们的最新文章排成时间线，
   头像、站点域名、时间、标题、摘要都有，点开在新标签页打开对方的文章。
   需要：给友链填上 RSS 地址，并在链接插件的「设置 → RSS 订阅」里勾上**「公开 RSS 订阅动态」**
   （这项默认关着，关着的时候公开接口是 404）。
   **RSS 地址不用自己找**：装上随主题带的「theme-x 助手」插件，去「内容 → 友链 RSS」点一下
   「一键发现并开启」，它会挨个访问友链的网站、扒出各自的 RSS / Atom 地址、填好开启并立刻抓一次，
   那个公开开关也能在同一页上点开（链接插件自己只在编辑单条友链的弹窗里提供「发现订阅地址」按钮）。
2. 没开、没填、或者还没抓到东西，就退回**友链列表**，一行一个站点，长得像 X 的「推荐关注」。
3. 连「链接」插件都没装的话，这个标签页是一句「还没有友链」的空状态——
   不想要就把来源换回「最多访问」，或者清空「第二个标签页」的名字，整条标签栏都不显示。

标签页的名字照样可以自己改（留空则不显示标签栏，从没设置过就跟随语言显示「正在关注 / Following」）。

## 文章列表的两种样式

同一批文章可以用两种看法，访客自己选：

| | X 时间线（默认） | 博客列表 |
| --- | --- | --- |
| 头像 / @用户名 | 有 | 没有 |
| 标题 | 正常字号 | 放大，作为主视觉 |
| 摘要 | 全文 | 两行封顶，次要文字色 |
| 封面 | 满宽大图 | 右侧 128×96 缩略图（手机 92×69） |
| 互动栏 | 六个按钮 | 收起 |
| 顶部发帖框 | 有 | 收起 |
| 时间 | 「4天」这种相对时间 | 「9月19日」这种绝对日期 |

**入口**：首页标签栏右边的小按钮，或者「显示」面板里的「列表样式」；选择存在访客自己浏览器里。
**默认值**在「外观 → 文章列表样式」里设。

左栏一收起就自动切到博客列表（见上一节），中栏同时变宽到 787px，缩略图跟着放大到 168×112。

作用范围是首页、探索、分类、标签和搜索结果；友链动态、瞬间、媒体页保持原样。
实现上只是在 `<html>` 上换一个 `data-feed`，用 CSS 重排同一套 DOM——不重新请求、不换地址，
无限滚动新加载的卡片自动跟着变。

## 媒体标签页

个人主页标签栏上的「媒体」，把所有**带封面图**的文章铺成 X 那样的三列方格，点开进文章。
（X 自己点开是进图片抽屉，但那对博客来说是条死路——看完一张图就没下文了，所以这里改成进文章。）

两步开起来：

1. 后台新建一个页面，别名随意（比如 `media`），「自定义模板」选「媒体」；
2. 把它的地址填到「主题设置 → 左栏导航 → 「媒体」标签指向的地址」。

**这一项留空，标签就不显示**——省得点出个 404。一页最多铺多少张在「文章 → 媒体页显示数量」里调，
默认 60 张，最多往前翻 500 篇文章找封面，超出的用一条「显示更多」引到归档页。

## 系列 / 专栏

Halo 没有「系列」这种东西，所以这里借分类来表达：**把一个分类的自定义模板选成「系列」**，
它下面的文章就自动成了一个连载。

- 分类页变成系列索引，文章按**发布时间正序**排，带序号、摘要和缩略图；
- 系列里的每篇文章顶上多一张卡片：「第 3 篇 / 共 7 篇」+ 整个系列的目录，当前这篇高亮；
- 一篇文章可以同时属于多个系列，那就出现多张卡片。

最多列几篇在「文章 → 系列最多列几篇」里调（默认 30，上限 200）。

> **别给系列分类勾「不显示在列表中」。** 勾上之后 Halo 的文章查询会把这些文章整个滤掉，
> 系列索引会变成「共 0 篇」，文章页上的卡片也不再出现。

> 排序用的是发布时间正序，而且是显式指定的——所以系列里就算有文章被设成置顶，也不会跳到第 1 篇去。

## 打赏

**默认关闭。** 去「主题设置 → 打赏」打开，至少配一种收款方式（微信码 / 支付宝码 / 第三种自定义码 /
站外收款页链接），按钮才会出现。位置可以勾「文章末尾」和「个人资料页」，
资料页上的那颗挨着「关注」按钮左边，和 X 的 Tips 一个位置。

## 正文里的几个开关

- **没设封面时用正文首图**（「文章 → 没设封面时用正文首图」，默认开）：文章没设封面时，
  列表里的封面退回正文里的第一张图。代价是这些文章的卡片要多读一次正文（实测首页多约 6ms），
  站点很大又在意首屏开销可以关掉。**「媒体」页只认真正设了封面的文章**，不受这一项影响。

- **文章目录**（「文章 → 文章目录」）：三档——只在「长文」模板里显示（默认）／所有文章都显示／不显示。
  目录是 JS 从正文的二、三、四级标题里抓的，标题少于两个就不画。
- **字数与阅读时长**（「文章 → 字数与阅读时长」）：同样三档。长文模板显示在标题下面，
  普通文章接在「N 次查看」后面。中文按每分钟 400 字、英文按 220 词估。
- **图片 ALT 徽标**（「功能 → 图片 ALT 徽标」，默认开）：正文和九宫格里**填了描述**的图片，
  左下角会出现一个 ALT 角标，点一下摊开描述，再点（或按 Esc、点别处）收起；
  灯箱里直接把描述铺在底下。没填 alt 的图片不显示角标——和 X 的规矩一样。
  文章封面不算（它用的是标题，不是描述）。

## 友链与申请

友链页（`/links`，要装官方「链接」插件）上有一块「申请友链」，**宽屏在右栏**（友链再多也不会被挤下去），
窄屏右栏本来就隐藏，这块就落到页面底部。只有这一页有，别的页面右栏不受影响：

- **上半部分是你自己的友链信息**——名称、地址、头像、描述，访客点「复制我的信息」一次性拿走。
  这几项在「主题设置 → 友链页」里填，留空就自动用站点标题 / 站点地址 / 个人资料头像 / 站点副标题。
- **下半部分是申请表单**——名称、地址、头像、描述、RSS、邮箱，加一张图形验证码，提交后直接进后台
  「链接 → 友链申请」等审核。RSS 那栏填了的话，通过之后对方的新文章就会出现在首页的「正在关注」里。
- 表单走「链接」插件的公开接口，需要在插件设置的「友链申请」里打开**「启用友链申请」**和
  **「允许访客提交」**。没开的话访客点「填写申请」只会看到一句说明，你的信息照常显示。
- 整块可以在「主题设置 → 友链页 → 友链申请入口」里关掉。申请须知也能自己写。
- **自动填写**（「友链页 → 申请表单自动填写」，默认关）：访客填好网址后，按对方网站上的信息把名称、简介、头像填好，
  只填空着的格子，访客改过的不会被覆盖。网页信息由访客浏览器去 api.miao.club 取。

### 友链体检

「theme-x 助手」插件 1.2.0 起带一页「内容 → 友链体检」：每隔一段时间（默认 24 小时）用
[api.miao.club](https://api.miao.club/#/api/site-check) 的「网站可用性检测」从外面访问每个友链，
列出哪些正常（状态码、耗时）、哪些打不开（无法解析域名、超时、404……）、哪些跳到了别的网站（域名过期被停放、整站搬家）。

- **只出报告**，不改友链、不影响前台。检测服务器在国内，连 GitHub Pages 这类站偶尔会超时，
  所以**连续 3 次**打不开才标成「失联」（次数可调），删不删、要不要联系对方你自己看着办。
- 设置在「插件 → theme-x 助手 → 设置」：开关、每隔几小时、连续几次算失联、api.miao.club 的 API Key。
- 检查是 Halo 服务器去请求 api.miao.club 的，不填 Key 用服务器 IP 的匿名额度（每天 100 次、每分钟 20 次），
  一轮最多查 90 条、每条隔 3.5 秒；友链更多的话注册个 Key 填上（每天 1 万次），没轮到的下一轮会优先查。
- 页面右上角「立即检查」可以马上查一遍，查的时候页面会自己刷新进度。

## 手机端

手机（< 500px）切成 X 的手机版布局：顶栏 + 底部 tab bar + 悬浮发帖按钮，
右栏的趋势、推荐关注整块收起（X 手机端也不显示，趋势去「探索」页看）。
500–999px（平板竖屏、半屏的桌面窗口）和 X 一样保留纯图标的左栏 + 600px 中栏，不进手机布局；右栏 ≥ 1050px 才出现。

为了把屏幕尽量留给内容，顶上永远只有一行：

- 首页、探索这两个根页面是「头像 · 标志 · 设置」的顶栏，页面自己的标题行让位
  （首页下面紧跟标签页，探索下面紧跟搜索框）；
- 其它页面（文章、分类、关于……）不再叠顶栏，只留「返回 + 标题」；
- 往下翻的时候顶栏、底部 tab bar 一起滑走，手指往下一拖（12px，页面不用真的滚动）就回来；
  离顶部 80px 以内、弹层开着、或者焦点在搜索框里时不收。不想要这个效果就在
  「功能 → 手机上滚动时收起顶栏和底栏」里关掉；
- 手机浏览器自带的下拉刷新默认拦掉（`overscroll-behavior-y: contain`，回弹和边缘光效照旧），
  免得想拉出顶栏时误触整页刷新；想要回来就把「功能 → 手机浏览器下拉刷新」改成「保留」；
- 时间线顶上的发帖框在手机上不显示，发帖走右下角的悬浮按钮。

**底栏第四格可以自己挑。** 五个格子里，前三格固定是首页、探索、分类，最后一格固定是个人资料，
中间那格在「左栏导航 → 手机底栏第四个位置」里选：书签（默认）／友链／瞬间／图库／标签／不显示。
「友链」「瞬间」「图库」都要先装对应插件，没装就别选，否则点进去是 404；选「书签」还得「功能 → 书签」是开着的。
选「不显示」时底栏只剩四格，剩下几格自动等分。

> 把书签从底栏换掉之后，手机上进书签页就只剩抽屉里那个入口了（由「内置导航项」控制）。
> 两边都去掉的话就真没路进去了——不过每条帖子上的收藏按钮照常能用，收藏本身不受影响。

抽屉只在根页面渲染——别的页面没有打开它的按钮（X 也是这样），渲染出来是死的，还白占两千多字节。

**点顶栏左上角的头像拉出侧边栏**，和 X 一样：头像、昵称、`@用户名`、关注数，
下面是整套导航，再下面是默认折叠的「设置与支持」，最底下一排是快速换肤的灯泡
（浅色 → 暗淡 → 夜间循环）、完整显示面板、关闭。点遮罩或按 <kbd>Esc</kbd> 关掉。

## ICP 备案号

在中国大陆境内提供服务的网站，工信部要求在页脚显著位置标明备案号并链到备案系统。
「右栏 → ICP 备案号」填上号码（例如 `豫ICP备20014910号-5`）即可，留空则整块不渲染。

填了之后会出现在三个地方，因为这套主题在不同宽度下页脚的位置不一样：

| 位置 | 什么时候可见 |
| --- | --- |
| 右栏页脚，跟在版权后面 | ≥ 1050px（右栏出现的宽度） |
| 页面最底下的一条通栏 | < 1050px |
| 手机抽屉里，「设置与支持」下面 | < 500px，点左上角头像拉出来 |

> **为什么手机上要放抽屉里。** 文章列表页开着无限滚动，页面底部那条会被越推越远、实际滚不到。
> 抽屉是手机端真正一直够得着的位置。如果你更希望底部那条能被看到，把「功能 → 无限滚动」关掉换成分页按钮。

号码链接固定指向 `https://beian.miit.gov.cn/`，带 `target="_blank" rel="noopener"`，并且不会被折行拆开。

## 右栏跟随滚动

右栏和 X 一样跟着页面走：搜索框始终吸顶；下面的小组件比屏幕高时，往下翻到它的底就停住，往回翻到它的顶停住。

「主题设置 → 右栏 → 跟随滚动的小组件」可以挑哪些跟随（默认全选）。**没勾选的会排到上面、随页面滚走，勾选的排在下面跟随**——
顺序是这个机制决定的：要滚走的东西必须在跟随的东西上面，不然会从它底下钻过去。一个都不勾就是老样子，整栏随页面滚走。

## 接入 api.miao.club 的几个小功能

[api.miao.club](https://api.miao.club) 是主题作者自己的聚合 API。主题没有服务端，下面这些都是**访客的浏览器直接去拿**，
所以**默认全关**，要不要让访客连第三方由你决定。都带跨域头；匿名额度是每个访客 IP 每天 100 次，每项都在访客本地缓存，
一个访客一天也就请求几次。返回的东西一律当不可信数据：文字只按纯文本写，链接只认 http(s)，图片只认 https。

| 功能 | 开关在哪 | 缓存 |
| --- | --- | --- |
| 右栏「有什么新鲜事」换成全网热榜 | 右栏 → 趋势卡片 → 全网热榜，再勾「热榜来源」 | 10 分钟 |
| 右栏「历史上的今天」 | 右栏 → 「历史上的今天」卡片 | 一天 |
| 发帖框里的「有什么新鲜事？」换成一句一言 / 古诗词 | 首页 → 发帖框里换成一句话 | 关掉标签页前不换 |
| 正文里单独一段的链接变成卡片 | 文章 → 正文链接变成卡片 | 每个网址 7 天 |
| 友链申请表单自动填写 | 友链页 → 申请表单自动填写 | 不缓存（访客填网址时才取） |
| 游戏限免 | 游戏限免 → 右栏「游戏限免」卡片 | 3 小时（可调） |

**正文链接卡片**只认「这一段就只有这一个链接」：编辑器里把网址单独贴成一段就行，链接夹在句子里的不动，
指向图片、PDF、压缩包的也不动。对方网站有分享图就是上图下文的大卡片，没有就是左边网站图标、右边标题和摘要的小卡片；
网页信息拿不到就保持原来的链接。一页最多变 8 张。

**历史上的今天**近的年份排在前面，先显示 4 条（可调），其余点「显示更多」展开，点了去百度百科。
它和别的右栏卡片一样可以在「跟随滚动的小组件」里勾选；1.23.0 之前保存过这一项、而且当时五项全勾着的，它也自动算勾上。

窄屏上右栏不显示，热榜和历史上的今天也就不去请求；博客视图里发帖框藏着，一句话也不去拿。

后台的「友链体检」也用 api.miao.club，不过那是 Halo 服务器去请求的，见[友链体检](#友链体检)。

## 游戏限免（Epic / Steam / GOG）

**默认是关掉的**，要用的话去「主题设置 → 游戏限免」打开。之所以默认关：这个卡片的数据是访客的浏览器直接去第三方接口取的，
要不要让访客连第三方应该由站长自己决定，不该在装上主题的那一刻就自己开起来。

右栏的限免卡片列出免费领取和即将限免的游戏（封面、截止时间、原价），点了直接去商店页。
**显示哪些平台**在「游戏限免 → 显示哪些平台」里勾，可以多选：

- 只勾 Epic（默认，也是升级前的样子）：卡片叫「Epic 限免」，每行末尾是发行商；
- 只勾一个别的平台：卡片叫「Steam 限免」或「GOG 限免」；
- 勾了多个：卡片叫「游戏限免」，每行末尾换成平台名。自己在「卡片标题」里填了名字的话，以你填的为准。

Epic 每周四换一批，几乎每周都有，还会提前公布下一批（「即将限免」）；Steam 和 GOG 的限免隔一阵子才有一次，也不会提前公布，
GOG 从来不给截止时间，Steam 大多也不给——这种就只写「限免中」。哪家这会儿没有，卡片里就只显示有的那几家。

想要一个完整的列表页：后台新建一个独立页面，模板选「游戏限免」，再把它的地址（比如 `/epic`）填到「游戏限免 → 『显示更多』链接」里
（留空时：只勾了一个平台就去那家商店的限免页，勾了多个就不显示「显示更多」）；
需要的话在「左栏导航 → 额外导航项」里加个入口（图标可以用 `ri:gamepad-line`）。手机上没有右栏，这个页面就是入口。

**数据从哪来。** 这几家商店的接口都不带跨域头，浏览器里直接调不了，而 Halo 主题没有服务端代码，所以数据是访客的浏览器去拿的。
Steam 和 GOG 的限免只有 [api.miao.club](https://api.miao.club/#/api/games-free) 的 `/api/games/free` 汇总了，勾了它们就走这个接口（一次请求一起拿）。
Epic 的来源可以换：

1. **「Epic 数据接口」留空就能用**：内置的第一个源是主题作者自己的 [api.miao.club](https://api.miao.club/#/api/epic) 的 `/api/epic/free`
   （带跨域头，匿名每个 IP 每天 100 次；访客浏览器里有几小时缓存，一个访客一天也就请求一两次）。
2. **想用自己的接口就填上**（「游戏限免 → Epic 数据接口」）。要求：返回 JSON、带 `Access-Control-Allow-Origin` 头；站点是 https 的话接口也得是 https。三种格式都认：
   - api.miao.club / 聚合 API：`{ code: 200, data: { current: [...], upcoming: [...] } }`，每项 `title / description / seller / originalPrice / startDate / endDate / url / image.wide`
     （旧版的 `original_price / start / end`、`image` 直接是字符串、`code: 0` 也认）；
   - Epic 官方接口原样反代：`{ data: { Catalog: { searchStore: { elements: [...] } } } }`（主题会自己挑出折后 0 元的那条促销）；
   - 60s / UAPI：`{ data: [{ title, cover, link, seller, original_price_desc, free_start_at, free_end_at }] }`。
3. 留空，或者自己的接口失败且允许退回时，依次试内置的接口：`api.miao.club` → `uapis.cn` → `60s.7se.cn` → `60s.crystelf.top`（2026-09 实测都带跨域头）。
   这意味着访客的浏览器会直连这些第三方；介意的话把「自己的接口失败时」改成「不退回」。公共实例由个人维护，哪天挂了卡片会自动消失，不会留个空壳。

用 Nginx 把官方接口反代成同源地址的写法（隐私最好，访客不接触任何第三方接口）：

```nginx
location = /epic-free.json {
  proxy_pass https://store-site-backend-static-ipv4.ak.epicgames.com/freeGamesPromotions?locale=zh-CN&country=CN&allowCountries=CN;
  proxy_set_header Host store-site-backend-static-ipv4.ak.epicgames.com;
  proxy_ssl_server_name on;
  proxy_cache_valid 200 1h;   # 需要先配好 proxy_cache 区
}
```

然后「Epic 数据接口」填 `/epic-free.json`。

几个细节：结果在访客浏览器里缓存（默认 3 小时，缓存里有游戏过了截止时间会提前重新拉）；请求不带 Cookie、不带 Referer；
接口返回的内容一律当不可信数据处理——文字只按纯文本写入，链接只认 https 的 `epicgames.com`，图片只认 https；
Epic 的封面原图能有好几 MB，主题给它家 CDN 的地址加了缩放参数，右栏缩略图只有十几 KB。

## 搜索

搜索走 Halo 自带的搜索索引（`/apis/api.halo.run/v1alpha1/indices/-/search`，2.17 起内置），正文也在检索范围内，命中词由服务端标出来。
以前是把全站文章按 100 篇一页全拉到访客浏览器里再本地过滤，两千篇的站点点一下搜索框就是好几兆流量，现在一次请求只取要显示的那几条。

站点关掉了索引、或者某个关键词把查询解析器弄炸时，会自动退回老的「拉全量再本地过滤」，功能不会消失。
关键词里的 Lucene 语法字符（`+ - & | ! ( ) { } [ ] ^ " ~ * ? : \\ / < >`）发出去之前会先换成空格——
这些字符会让索引接口直接 500，实测搜「<script>」就能复现。

## 多语言

界面文案全部走 Halo 的消息表达式，语言文件在主题根目录的 `i18n/`：

- `default.properties` — 默认（简体中文），任何语言匹配不上时用它
- `zh_CN.properties` — 简体中文
- `en.properties` — English

加一门语言就照着复制一份，文件名用 `<语言代码>.properties`。值里的中文要写成
`\uXXXX` 转义（properties 文件是 latin-1）。

日期格式也在里面：`format.date`、`format.dateShort`、`format.dateTime`，
按 Java 的 `DateTimeFormatter` 语法写。

`theme.js` 里的文案由 `head.html` 通过 `window.__X_I18N__` 传进去，脚本里每处都带
了中文兜底——就算消息文件整个读不到，界面也不会变成空白。

## 右栏与趋势卡

**「有什么新鲜事」可以换成全网热榜。** 「右栏 → 趋势卡片」选「全网热榜（api.miao.club）」，
再在「热榜来源」里勾想要的：微博、知乎、B 站、抖音、百度、头条、GitHub Trending、V2EX、IT之家、36氪、少数派、Hacker News。
勾了几个，卡片标题下面就有几个按钮，访客点哪个看哪个（记在访客浏览器里）；条目数用「趋势条目数」。
每条显示排名、标题和这个平台自己的热度（微博是搜索量、B 站是播放量、GitHub 是今天新增的星……），点了去原站。
热榜在访客浏览器里缓存 10 分钟；哪个来源一时拿不到就不显示那个按钮，全都拿不到整块卡片不出现。
接口服务器在国内，GitHub、V2EX、Hacker News 偶尔连不上。


趋势卡只把「够得着前 N 名」的那几条渲染出来：服务端先把所有标签的文章数排一遍，取出第 N 名的数当分数线，再按分数线过滤，
真正的排序和裁剪在 `theme.js` 的 `initTrends` 里完成。几百个标签的站点不会每页白吐几百行看不见的 HTML；没有 JS 时看到的也是这几条（只是没排序）。


**后台留空的文案会跟随站点语言。** 标签页名字、发帖按钮、搜索框提示、订阅卡、趋势卡标题、版权声明这些，
`settings.yaml` 里不再写死中文默认值——没填就用 `i18n` 里对应语言的文案。已经填过的保持不变，想恢复成跟随语言就把输入框清空。
例外是「第二个标签页」：清空表示不显示标签栏，从没设置过才跟随语言显示「正在关注 / Following」。

**英文的单复数。** 模板里的数量后缀按数量选 `unit.post` / `unit.posts` 这样的单复数键；
脚本里的文案用竖线写两份，例如 `js.newPosts=Show {0} new post|Show {0} new posts`，`t()` 会按第一个参数挑一份。
中文两份写一样就行。**翻译值里因此不能随便出现竖线**，需要竖线又带参数时请换个写法。

**强调色当文字用的时候会压深一档。** 六种强调色当按钮底色、标签页下划线时一律用 X 的原色；
但橙、绿、黄这三种直接当链接文字时在浅色背景上分别只有 2.6 / 2.5 / 1.4 的对比度（X 自己的蓝是 3.0），
所以浅色背景下这三种换成各自深一档的色（`--accent-text`）。想要和 x.com 逐像素一致，把 `main.css` 里那三条 `--accent-text` 删掉即可。

## 无障碍与 SEO

弹层（显示设置、搜索结果、快捷键、抽屉、灯箱）打开时，Tab 只在弹层内部循环，
页面主体连同底部 tab bar 一起被标上 `inert` 和 `aria-hidden`，读屏不会念到背后的内容；
<kbd>Esc</kbd> 关闭后焦点回到打开它的那个按钮。

每个页面都带 `canonical`（由 `site.url` 加 permalink 拼成绝对地址）、正确的
`og:type`（文章是 `article`，个人页是 `profile`，其余 `website`）以及 `og:url`。
文章页附 `Article` 结构化数据，首页附 `WebSite`。错误页刻意不输出 canonical。
友链、瞬间、图库这三个插件页没有稳定的 permalink 变量，也不输出——宁可不写，
也好过写错一个。

**链接类设置填什么都不会把站点弄崩。** 左栏发帖按钮、额外导航项、订阅卡、页脚链接、推荐关注、个人网站这些地方，
填的值会先归一化：`/` `#` `http(s)://` `mailto:` 原样用，其余当成漏写协议补上 `https://`。
（Thymeleaf 的链接表达式遇到 `javascript:` 是抛异常而不是过滤，而这些片段每页都渲染，一旦抛异常整站都会白屏，所以这一层必须有。）

**评论区跟着站点开关走。** 后台关掉评论、或者没装评论插件时，文章和页面底部不会留一个空的「回复」外壳。

**「个人资料」指向哪里可以配。** 默认 `/about`（Halo 初始化时自带这个页面），删掉或改名了就去「左栏导航 → 「个人资料」指向的地址」改。

## 有几件事值得先知道

**置顶用 Halo 自己的。** 后台「文章」列表里把文章设为置顶，首页就会把它排在最前面并带上
「已置顶」标记，可以同时置顶多篇。主题设置里不再有单独的「置顶文章」——1.14.0 之前有过，
在那儿选过的话，改到文章管理里置顶一次就行。

**名字和头像只在一个地方设。** 「主题设置 → 个人资料」里的头像、显示名、用户名是全站唯一的身份：
左栏、手机抽屉、关于页、留言板，以及所有文章和瞬间卡片都用它，Halo 账号（左下角那个）里的显示名称和头像不用再管。
多人博客想让每篇文章显示真正的作者，把「个人资料 → 文章卡片上的署名」改成「用各文章作者的 Halo 账号」。
（1.21.0 之前文章卡片默认用 Halo 账号、左栏用主题设置，两边不填成一样就会一处一个名字。）

**显示设置存在访客那边。** 背景、强调色、字号、头像形状都写进访客浏览器的
`localStorage`，主题设置里配的只是初始值。访客自己改过之后，站长再改配置就不会
影响他了——和 X 的行为一致。

**书签也是本机的。** 收藏列表存在 `localStorage` 里，不上传、不同步，换设备或者
清了浏览器数据就没了。书签页顶部有个清空按钮。

**搜索是前端搜的。** 首次聚焦搜索框时会按页把文章列表拉下来（一页 100 条，最多 20
页）缓存到 `sessionStorage`，之后在本地按标题、摘要、标签过滤。不依赖任何搜索插件。
输入时下拉给 8 条建议，回车或点「查看全部」打开完整结果页。代价是超过 2000 篇的站点
搜不到最后那部分，而且中文没有分词，只做子串匹配。

**「喜欢」走 Halo 的点赞接口**（`trackers/upvote`），计数是真的；本机是否点过存在
`localStorage`，所以刷新之后仍然是「已喜欢」。**「转发」只是复制链接**——博客没有
真正的转发，按钮保留是为了让互动栏的形状对得上 X，不会伪造任何数字。

**趋势榜的顺序在前端排。** 模板把全部标签（或分类）连同文章数一起渲染出来，
JS 按文章数倒序重排并截断到配置的条数。关掉 JS 就是后台的原始顺序。

**首页第二个标签页是点开才加载的。** 服务端只吐一个空容器，点到那个标签时前端去取
现成的分类页或归档页，把里面的时间线搬过来。选「最多访问」时取的是归档页第一页再按
访问量重排，所以它是「最近这些文章里最热的」，不是全站热门榜。
选「友链」时不取页面，改调「链接」插件的两个公开接口（`/apis/api.link.halo.run/v1alpha1/linkfeeds`
和 `/links`），也是点开才请求。

**评论区会跟着主题变色。** Halo 的评论组件把 DOM 关在 Shadow Root 里，外部选择器进不去，
能改的只有它暴露的 CSS 变量。这套变量名是对着 comment-widget 3.1.2 的 shadow root 逐个核出来的
（前缀是 `--halo-cw-`，不是文档里常见的那串长名字），已经映射到主题色板：强调色、正文/次要文字、
三档描边底色、头像尺寸与形状、字体、圆角都跟着走，切背景和换强调色时评论区一起变。
组件内部的排版仍然是它自己的，主题只在外面套了 X 的回复区外壳。

**无限滚动有两道触发。** 主要靠 IntersectionObserver 盯住列表底部的哨兵，另外挂了一道
滚动兜底——页面在后台标签页、窗口被完全遮挡时浏览器不跑渲染步骤，IntersectionObserver
就不会回调，只有哨兵一条路的话会整个哑掉。滚到底自动接下一页，接完显示「没有更多了」。

**地址栏不会跟着翻页变。** 翻了几页之后点进文章再返回，靠的是把「翻到第几页 + 滚到哪儿」
记在 `sessionStorage`（同路径、30 分钟内、最多补回 10 页），回来自动补齐再落到原位置。
改地址栏的做法会让「返回」落到 `/page/N` 只剩那一页，所以没采用。

**代码高亮按需加载，并且会给插件让路。** 页面里真的有 `<pre>` 才会去拉 highlight.js，
token 配色是主题自己写的，三套背景都对得上，不会再多拉一个样式文件。CDN 打不开就退回
纯文本，边框和复制按钮照常。如果站点已经装了代码高亮插件（shiki、highlight、prism
这类），主题会自动检测到并完全不介入，交给插件渲染——否则两套高亮会各画各的。

**图片走 Halo 的缩略图接口**（`thumbnails/-/via-uri`），每张图都带了原图地址做兜底：
接口取不到、或者这个 Halo 版本没有这个接口，前端会自动换回原图。不放心可以在
「功能 → 图片缩略图」里关掉。

**图标依赖 iconify 的 CDN。** 脚本和图标数据都从 CDN 取，打不开的话图标会是空白。
介意的话把 `iconify-icon.min.js` 下载下来传到附件里，在「外观 → 图标脚本地址」换成
自己的地址。代码高亮脚本同理。

**1.5.0 之前「功能」分组里的开关对脚本那一半不起作用。** Thymeleaf 的 JS 内联会把 `/*[[${x}]]*/ "on" !== "off"` 里注释后面的默认值整段替换掉，
脚本拿到的是字符串 `"on"` / `"off"`，两个都为真——无限滚动、快捷键、灯箱这些关了等于没关。现在模板只输出原始值，布尔化放在 theme.js 开头的
`var CFG =` 那段里。二次开发往 `window.__X__` 加开关时照这个写法来，别在内联注释后面写表达式。

## 二次开发

改模板之前先记住 Halo 里 SpEL 的一个脾气：**在 null 上继续取属性不会报错（得到 null），
但在一个非空对象上取它没有的属性会直接抛异常**，整页渲染中断。实测踩过的坑：作者页拿到的是
`UserVo`（字段在 `spec` 下）而不是 `ContributorVo`；`CategoryVo` 没有 `children`（在 `spec.children`，
是名字数组）；`MomentVo` 没有 `status`；图库插件不传 `group`，要读 `param.group`。
另外 **不要用 `postFinder.getByName` / `categoryFinder.getByName` 去取配置里存的名字**——
对象被删后它们会抛 `ExtensionNotFoundException`，模板里没法 catch。改用 `list()` / `listAll()` 再按名字比对。

`theme.js` 里所有会被动态插入的 DOM 都要过一遍 `enhance(root)`，否则新节点上的
相对时间、点赞状态、书签状态不会生效。这个函数挂在 `window.XTheme` 上：

```js
XTheme.enhance(newNode);   // 给新插入的节点补上交互
XTheme.toast("保存好了");   // 底部提示条
XTheme.formatCount(12840); // "1.3万"
```

自定义 CSS / JS 和 head、body 注入都在「主题设置 → 高级」里。
